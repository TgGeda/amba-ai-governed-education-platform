# Contributing to AMBA-GOV

Contributions must preserve deterministic governance, evidence provenance, fail-closed behavior, and test coverage. Submit changes on a focused branch with a clear rationale, affected controls, tests, migration impact, and generated-artifact hashes. Do not commit personal data, credentials, production secrets, unapproved legal claims, or unverified evidence. Changes to policy authority, scoring methodology, security controls, or evidence eligibility require explicit review and must not be hidden inside refactoring.
