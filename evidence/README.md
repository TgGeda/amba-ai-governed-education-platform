\# Amba-Gov Evidence Metadata



Package ID: AMBA-GOV-EVIDENCE-2026-10-30



This directory contains portable integrity and verification metadata for the

external evidence used by Amba-Gov.



\## Included metadata



\- SHA-256 identities for source artifacts

\- PDF header-validation results

\- Portable artifact inventories

\- Reference-framework checksums

\- Evidence-package verification status



\## External artifacts



The source PDFs and reference archives are maintained outside this Git

repository. Their local bytes may be checked against:



`evidence/checksums/source\_checksums.sha256`



Raw external documents are excluded from the repository to avoid unnecessary

binary storage and to preserve separate handling of redistribution and

licensing conditions.



\## Verification boundary



Artifact-integrity verification confirms the identity of locally acquired

bytes within the verified scope.



It does not establish:



\- formal legal review;

\- official translation status;

\- legal applicability to a specific actor or operation;

\- licensing or redistribution permission;

\- ITU certification;

\- formal ITU-T Y.3172 conformance;

\- Ethiopia's national AI readiness.



The project describes its audit records as "tamper-evident within verified

scope", not "tamper-proof".
