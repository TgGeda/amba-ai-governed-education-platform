# AMBA-GOV Accessibility Evaluation Protocol

## Scope

This protocol evaluates the demonstrable desktop interface and evidence-chain outputs against selected WCAG 2.2 AA-oriented criteria. It is not a formal WCAG certification.

## Required checks

- Keyboard-only navigation for every evaluated workflow
- Visible focus indication
- Programmatic or visible labels for interactive controls
- Text resizing to 200 percent without loss of essential function
- Contrast measurement for normal text, large text, and interactive components
- Status messages and validation errors presented without relying only on color
- Reading order and accessible naming where supported by the UI toolkit
- Explicit record of tested and untested criteria

## Evidence record

For every check, record criterion, test method, evaluated component, result, limitation, evidence file, and SHA-256. Synthetic or automated checks must be identified as such.
