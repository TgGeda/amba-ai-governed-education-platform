# Amba-Gov Knowledge Base

This directory stores repository-level evidence and retrieval artifacts.

The authoritative evidence layers are:

1. Original artifact
2. Extracted text with page provenance
3. Normalized text
4. Curated PolicyRecord
5. RetrievalChunk

A RetrievalChunk is a search representation and is not independently eligible
for binding use.

A binding finding requires an active PolicyRecord with the required artifact,
metadata, locator, applicability, licensing, and activation statuses.

Project controls may support project enforcement but are not Ethiopian national
law.
