# Amba-Gov Authoritative Source Corpus

This directory contains the nine hash-verified source PDFs used by Amba-Gov.

Artifact verification establishes file presence, PDF magic-header validity,
and exact SHA-256 identity. It does not establish legal review, official
translation status, legal applicability, ITU certification, or formal
ITU-T Y.3172 conformance.

Ethiopian sources are stored under `ethiopia`.
International technical and supporting sources are stored under `international`.

Run:

`tools\evidence\capture_authoritative_source_verification.cmd`

before corpus extraction or index generation.
